# Ahmed Alam's Portfolio

I made this with React Vite, Convex, and Discord to view live messages on my mobile with ip address, geo-location, name, email, and message. BTW I'm 16y old and made this while learning Convex. Since 1y I don't have a good portfolio before making this lol. Thanks to HackClub for making coding fun again.

# Install & Run

First create a [Convex](https://convex.dev) account if you haven't, then
simply clone the repository and install packages.

```bash
git clone https://github.com/xahmedalam/cu-portfolio
```

```bash
npm install
```

then

```bash
npm run dev
```
and you're good to go...
